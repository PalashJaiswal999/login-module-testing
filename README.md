# Login Module Testing

## Project Overview
This project demonstrates manual testing of a Login Module using software testing methodologies and documentation.

## Testing Scope
The following areas were covered:
- Valid Login
- Invalid Login
- Field Validation
- Boundary & Negative Testing
- Error Message Validation
- Functional Testing

## Testing Activities
- Requirement Analysis
- Test Scenario Preparation
- Test Case Design
- Test Execution
- Requirement Traceability

## Testing Documentation
The Excel workbook contains:
- Requirements
- Test Scenarios
- Test Cases
- RTM (Requirement Traceability Matrix)

## Tools Used
- Microsoft Excel
- Manual Testing
